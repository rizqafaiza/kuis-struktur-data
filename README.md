# Deskripsi Program
<ul>
  <li>Sistem Pengelolaan Nilai Mahasiswa: data mahasiswa disimpan di dalam linked list dan nilainya disimpan di dalam dinamic array.
                                          Pengguna diminta memasukkan data mahasiswa dan nilai mahasiswa. Pengguna bisa mencari data mahasiswa
                                          menggunakan linear search. Nilai mahasiswa juga dapat dicari menggunakan binary search yang
                                          sudah diurutkan menggunakan insertion sort.</li>
  <li>Sistem Antrean dan Pengelolaan Buku Perpustakaan: Program yang mencatat ID buku dalam sebuah linked list dan ditampilkan secara preorder, inorder, dan postorder.
                                                        Antrean peminjaman buku disimpan dalam sebuah queue yang berbentuk FIFO. Sedangkan riwayat pengembalian buku
                                                        disimpan dalam stack berbentuk LIFO</li>
  <li>Sistem Pencarian Rute di Lingkungan Kampus: Program yang memberikan rute dan jarak terpendek dari 6 titik di kampus. Terdapat pencarian titik yang dilakukan
                                                  secara BFS dan DFS. Selain itu, pengguna dapat mencari rute terpendek menggunakan algoritma djikstra kemudian
                                                  program menampilkan rute terpendek beserta total jaraknya.</li>
  <li>Sistem Pengelolaan Data Mahasiswa menggunakan Hash Table: Sebuah sistem yang mengelola data mahasiswa dan menyimpannya dalam table hash. Pengguna dapat melakukan
                                                                insert, remove, search, dan menampilkan data. Penanganan collision dilakukan dengan metode double hashing. </li>
</ul>
